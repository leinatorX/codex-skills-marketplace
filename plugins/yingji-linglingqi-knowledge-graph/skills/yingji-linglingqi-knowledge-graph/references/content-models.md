# 内容模型与选题库

## 认错风险模型

适用主题：

- 设备类型
- 罐体类型
- 消防接口
- 报警器
- 灭火剂
- 危化品标识
- 消防车种类
- 应急装备识别

核心逻辑：用户以为“看起来差不多”，但实际“风险完全不同”。

标准结构：

1. 图 1：这几种东西认错很危险。
2. 图 2：认错后会造成什么后果。
3. 图 3：类型识别表。
4. 图 4：结构差异图。
5. 图 5：适用场景对照表。
6. 图 6：常见误区红黑榜。
7. 尾图：选择题 / 猜名称 / 找错题。

标题参考：

- 这几种 XX，认错真的很危险
- 看着都像 XX，风险完全不同
- 别把 XX 当成 XX
- 外形相似，不代表用法相同
- 关键时刻，认错就麻烦了

## 设备拆解模型

适用主题：消防车、灭火器、消防水炮、水泵接合器、防火门、室外消火栓、消防机器人、战勤保障装备。

核心逻辑：用户见过这个设备，但不知道里面有什么、怎么工作、适合什么场景。

标准结构：

1. 图 1：设备整体拆解，突出“原来里面是这样”。
2. 图 2：它和相似设备有什么区别。
3. 图 3：关键结构标注。
4. 图 4：作业流程。
5. 图 5：适用场景。
6. 图 6：常见误区。
7. 尾图：猜设备 / 选用途 / 找错题。

标题参考：

- 很多人见过 XX，但不知道它怎么救命
- XX 不是只有外壳，关键在这几个部件
- 这台 XX，关键时刻靠这些系统救命
- 别只看外形，真正关键的是里面这些结构

## 流程避错模型

适用主题：危化企业前期处置、初起火灾处置、商场起火处置、矿山巷道事故处置、报警联动流程、应急预案启动流程。

核心逻辑：流程类内容不要先讲“标准流程”，要先讲“第一步做错会怎样”。

标准结构：

1. 图 1：前几分钟最怕做错。
2. 图 2：最危险的 5 个错误动作。
3. 图 3：正确总流程。
4. 图 4：0-1 分钟动作卡。
5. 图 5：1-3 分钟协同卡。
6. 图 6：分场景判断表。
7. 尾图：如果你在现场，第一步选哪个？

标题参考：

- XX 出事，第一步千万别乱做
- 前 3 分钟，最怕这几个动作
- 不是没人救，是救错了更危险
- 先别冲上去，顺序错了风险更大

## 泛安全提醒改造模型

适用主题：节假日安全、出行安全、家庭安全、校园安全、社区安全。

核心逻辑：泛安全内容天然像宣传提醒，必须改造成具体风险场景。

标准结构：

1. 图 1：不是怕 XX，是怕这些小事出问题。
2. 图 2：最容易翻车的 5 个瞬间。
3. 图 3：出发前 / 使用前 / 检查前清单。
4. 图 4：错误行为红黑榜。
5. 图 5：不同人群或场景提醒。
6. 图 6：最容易忽略的细节。
7. 尾图：你最担心哪一种？

## 标识 / 编码类模型

适用主题：危化品车数字、UN 编号、危险性识别号、危险品菱形牌、消防设施标识、管道颜色、安全色和安全标志、灭火器压力表颜色。

核心逻辑：用户看到数字、颜色、标识，但不知道具体含义。必须先解码，再讲风险。

标准结构：

1. 图 1：直接解码一个具体示例。
2. 图 2：这个含义对应什么风险和避险动作。
3. 图 3：速查表，讲清位置、数字、含义、用途。
4. 图 4：常见误读对照。
5. 图 5：报警 / 处置时怎么说。
6. 图 6：错误做法和正确做法。
7. 尾图：看图选择题或猜含义。

标题参考：

- `33/1203` 到底是什么意思？
- 看到这个数字，先别靠近
- 危化车尾牌，不是车牌
- 上面看风险，下面看物质
- 这组数字，报警时要说清

首图避免：

- 危化车数字不是装饰
- 危化车数字很重要
- 别把识别信息当装饰
- 看错可能救错

这些可以作为副标题或图 2 后果，不能替代具体含义。

## 标识 / 编码示例：危化品车 `33/1203`

前两张必须直接讲：

- `33 = 高度易燃液体`
- `1203 = 汽油`
- 菱形牌 `3 = 第 3 类易燃液体`

推荐分图：

1. 图 1：`33/1203 是什么？`
   - `33 = 高度易燃液体`
   - `1203 = 汽油`
   - `3 类 = 易燃液体`
2. 图 2：为什么不能靠近？
   - 汽油蒸气遇火更危险
   - 高度易燃，远离明火
   - 先远离，再报警，说清数字
3. 图 3：橙色矩形牌怎么读。
4. 图 4：上方数字速查。
5. 图 5：菱形牌看危险类别。
6. 图 6：特殊标志看额外风险。
7. 图 7：报警话术卡。
8. 图 8：尾图选择题。

常见危险性识别号简化含义：

- `20`：导致窒息的气体
- `23`：易燃气体
- `30`：易燃液体
- `33`：高度易燃液体
- `50`：氧化性物质
- `60`：毒性物质
- `80`：腐蚀性物质
- `X80`：遇水会发生危险反应的腐蚀性物质

使用提醒：

- 重复数字表示强调该类危险性。
- 末尾加 `0` 通常表示单一危险性由一个数字表示。
- `X` 开头表示遇水会发生危险反应。
- 具体解释以现行法规、标准或官方资料为准。

## 选题池

高优先级：

- 消火栓和水泵接合器，很多人真分不清
- 化工厂这 5 种消防设备，认错真的很危险
- 这 4 种报警器，响了不代表都一样
- 喷淋头、烟感、温感，别再混着叫了
- 危化品车后面的数字，不是车牌
- 油锅起火为什么不能浇水？
- 电器起火为什么不能先泼水？
- 有限空间救人，为什么不能第一个冲进去？
- 地下车库这些消防设备，你认得几个？
- 商场起火为什么不能坐电梯？

中优先级：

- 防火门为什么不能常开？
- 仓库冒烟后，第一反应别开门
- 消防车这 6 个接口，接错关键时刻没水
- 干粉消防车到底灭什么火？
- 泡沫消防车为什么不是只装泡沫？
- 加油站这几个红线动作，别碰
- 化工厂看到白雾，是水蒸气还是泄漏？
- 小区消防通道为什么不能占？
- 初起火灾扑救，什么时候该放弃灭火？
- 动火作业没审批，最危险的不是罚款

账号边界：

- 核心层 60%：消防设备识别、应急装备拆解、危化设施识别、错误操作后果。
- 扩展层 30%：商场、仓库、小区、地下车库、加油站、餐饮后厨、工业现场危险识别、事故前兆识别。
- 外围层 10%：节假日安全、法规政策、应急预案、管理流程。

宽泛可以，但每个选题都要落到三件事之一：认错、用错、判断错。
