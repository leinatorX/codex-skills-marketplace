# 内容模型与选题库

## 前两图留人模板

所有内容模型都先套前两图留人模板，再展开中间收藏页。目标不是把知识讲全，而是先让用户停住并继续翻。

### 通用公式

- 图 1：具体对象 + 认知冲突 + 半个答案。
- 图 2：具体后果 / 强对比 / 反常识 / 第一步避错 / 具体解码。
- 图 3：进入收藏页，用表格、清单、流程卡或识别图兑现价值。

### 首图标题公式

优先使用：

- `这 4 种 XX，认错风险不一样`
- `看到 XX，先看这 1 处`
- `XX 不是 XX，第一步别做反`
- `这组数字，先报哪两个？`
- `安全员最容易漏查这 3 处`
- `看着都像 XX，其实差在这里`

避免使用：

- `XX 知识图谱`
- `XX 类型介绍`
- `XX 作用详解`
- `XX 很重要`
- `XX 不是装饰`
- `你知道 XX 吗`

### 图 2 承接公式

从下面 5 种里选 1 种，不要混写：

- 后果揭示：`认错后，最容易错在这一步`
- 强对比：`左边能做 A，右边不能做 A`
- 反常识：`不是先靠近看清，而是先远离报数`
- 第一步避错：`现场第一眼先看这里`
- 具体解码：`上面数字看风险，下面数字看物质`

### 前两图示例

危化 / 标识类：

1. 图 1：`33/1203 到底在提醒什么？`
   - `33 = 高度易燃`
   - `1203 = 汽油`
   - 悬念：为什么不能靠近拍照？
2. 图 2：`先远离，再报这组数字`
   - 不是车牌，是风险信息。
   - 报警先说位置，再说 `33/1203`。
   - 继续翻页理由：第 3 张给你一张速查表。

消防设施类：

1. 图 1：`这两个接口，接错可能没水`
   - 水泵接合器
   - 室外消火栓
   - 悬念：一个给车取水，一个给楼加压。
2. 图 2：`外形像，任务完全不同`
   - 消火栓：消防车取水。
   - 接合器：给建筑管网加压供水。
   - 继续翻页理由：第 3 张教你看位置和标识。

安全员 / 巡检类：

1. 图 1：`安全员最容易漏查这 3 处`
   - 动火点
   - 气瓶间距
   - 临时用电
   - 悬念：漏掉一个，现场风险会变大。
2. 图 2：`不是有没有证，是现场有没有变`
   - 票证只是开始。
   - 风向、火花、可燃物、监护人更要看。
   - 继续翻页理由：第 3 张给巡检顺序卡。

## 长期栏目组合

账号长期发展优先做“垂直信任”，不是追泛热点。选题排期默认按 60% 核心爆款线、25% 职业价值线、15% 热点解释线组合；如果用户给出新数据，再按数据调整比例。

### 核心爆款线：60%

目标：稳住播放和涨粉。

适用主题：

- 危化 / 化工 / 储罐 / 装卸 / 泄漏。
- 消防装备 / 消防设施 / 标识识别。
- 现场第一步避错。

前两图策略：

- 图 1 用具体设备、具体数字、具体错误动作制造停顿。
- 图 2 只讲一个后果、强对比或第一步避错。
- 图 3 必须给可收藏表格或识别卡。

### 职业价值线：25%

目标：沉淀安全员、班组长、企业培训和资料包价值。

适用主题：

- 特种作业 / 特殊作业。
- 动火、受限空间、临时用电、高处作业。
- 安全检查、台账、SDS、作业票、班前会。
- 新规、标准、目录和证书边界。

前两图策略：

- 图 1 不写政策标题，改写成“现场会错在哪里”。
- 图 2 给一个真实管理判断，例如“有证不等于这次能干”。
- 图 3 给检查清单、流程卡或红黑榜。

### 热点解释线：15%

目标：承接平台流量，但不稀释账号定位。

适用主题：

- 事故通报后的安全机制解释。
- 热点事件里的消防、危化、应急处置逻辑。
- 节假日、天气、校园、社区、家庭安全，但必须落到具体场景。

前两图策略：

- 图 1 不做泛情绪，必须落到具体风险动作。
- 图 2 解释“为什么普通做法可能错”。
- 图 3 给普通人可用的判断卡或避险卡。

## 钩子轮换规则

连续排期时必须轮换首图钩子，避免用户形成疲劳。

可轮换的 6 类钩子：

- 认错钩子：`这 4 种 XX，认错风险不一样`
- 用错钩子：`XX 不是这样用的`
- 第一步钩子：`第一步别先做这件事`
- 数字解码钩子：`这组数字，先看上面还是下面？`
- 查漏钩子：`安全员最容易漏查这 3 处`
- 判断题钩子：`看到这个现场，你先选哪一步？`

排期限制：

- 连续 3 条不能都用“第一步别错”。
- 连续 3 条不能都用“认错危险”。
- 法规 / 标准类标题不能连续写政策名称，必须穿插现场判断题。
- 泛安全主题必须先改造成认错、用错、判断错之一。

## 样本沉淀规则

每次复盘后，把作品分成 3 类样本，用于下一次选题判断：

- 强样本：播放、收藏或涨粉明显高于账号中位数，保留选题主线和前两图结构。
- 中样本：收藏不错但播放一般，保留中间收藏页，重做首图包装。
- 弱样本：平均浏览图片低、评论低、收藏低，优先判断首图是否抽象、图 2 是否定义化。

复盘时不要只看播放量，还要同时看平均浏览图片、封面点击率、收藏量和评论量。

## 认错风险模型

适用主题：

- 设备类型
- 罐体类型
- 消防接口
- 报警器
- 灭火剂
- 危化品标识
- 消防车种类
- 应急装备识别

核心逻辑：用户以为“看起来差不多”，但实际“风险完全不同”。

标准结构：

1. 图 1：具体指出哪几种东西容易认错，并露出一个关键差异。
2. 图 2：只讲认错后的一个具体后果或强对比。
3. 图 3：类型识别表。
4. 图 4：结构差异图。
5. 图 5：适用场景对照表。
6. 图 6：常见误区红黑榜。
7. 尾图：选择题 / 猜名称 / 找错题。

标题参考：

- 这几种 XX，认错真的很危险
- 看着都像 XX，风险完全不同
- 别把 XX 当成 XX
- 外形相似，不代表用法相同
- 关键时刻，认错就麻烦了

## 设备拆解模型

适用主题：消防车、灭火器、消防水炮、水泵接合器、防火门、室外消火栓、消防机器人、战勤保障装备。

核心逻辑：用户见过这个设备，但不知道里面有什么、怎么工作、适合什么场景。

标准结构：

1. 图 1：设备整体拆解，突出一个用户没想到的关键部件。
2. 图 2：它和相似设备的一个关键差异，不讲完整组成。
3. 图 3：关键结构标注。
4. 图 4：作业流程。
5. 图 5：适用场景。
6. 图 6：常见误区。
7. 尾图：猜设备 / 选用途 / 找错题。

标题参考：

- 很多人见过 XX，但不知道它怎么救命
- XX 不是只有外壳，关键在这几个部件
- 这台 XX，关键时刻靠这些系统救命
- 别只看外形，真正关键的是里面这些结构

## 流程避错模型

适用主题：危化企业前期处置、初起火灾处置、商场起火处置、矿山巷道事故处置、报警联动流程、应急预案启动流程。

核心逻辑：流程类内容不要先讲“标准流程”，要先讲“第一步做错会怎样”。

标准结构：

1. 图 1：直接点出第一步最容易做错的动作。
2. 图 2：只讲这个错误动作会带来的具体后果。
3. 图 3：正确总流程。
4. 图 4：0-1 分钟动作卡。
5. 图 5：1-3 分钟协同卡。
6. 图 6：分场景判断表。
7. 尾图：如果你在现场，第一步选哪个？

标题参考：

- XX 出事，第一步千万别乱做
- 前 3 分钟，最怕这几个动作
- 不是没人救，是救错了更危险
- 先别冲上去，顺序错了风险更大

## 泛安全提醒改造模型

适用主题：节假日安全、出行安全、家庭安全、校园安全、社区安全。

核心逻辑：泛安全内容天然像宣传提醒，必须改造成具体风险场景。

标准结构：

1. 图 1：把泛提醒压成一个具体场景或具体错误动作。
2. 图 2：讲一个最容易翻车的瞬间，不直接铺开 5 个提醒。
3. 图 3：出发前 / 使用前 / 检查前清单。
4. 图 4：错误行为红黑榜。
5. 图 5：不同人群或场景提醒。
6. 图 6：最容易忽略的细节。
7. 尾图：你最担心哪一种？

## 标识 / 编码类模型

适用主题：危化品车数字、UN 编号、危险性识别号、危险品菱形牌、消防设施标识、管道颜色、安全色和安全标志、灭火器压力表颜色。

核心逻辑：用户看到数字、颜色、标识，但不知道具体含义。必须先解码，再讲风险。

标准结构：

1. 图 1：直接解码一个具体示例。
2. 图 2：这个含义对应什么风险和避险动作。
3. 图 3：速查表，讲清位置、数字、含义、用途。
4. 图 4：常见误读对照。
5. 图 5：报警 / 处置时怎么说。
6. 图 6：错误做法和正确做法。
7. 尾图：看图选择题或猜含义。

标题参考：

- `33/1203` 到底是什么意思？
- 看到这个数字，先别靠近
- 危化车尾牌，不是车牌
- 上面看风险，下面看物质
- 这组数字，报警时要说清

首图避免：

- 危化车数字不是装饰
- 危化车数字很重要
- 别把识别信息当装饰
- 看错可能救错

这些可以作为副标题或图 2 后果，不能替代具体含义。

## 标识 / 编码示例：危化品车 `33/1203`

前两张必须直接讲：

- `33 = 高度易燃液体`
- `1203 = 汽油`
- 菱形牌 `3 = 第 3 类易燃液体`

推荐分图：

1. 图 1：`33/1203 是什么？`
   - `33 = 高度易燃液体`
   - `1203 = 汽油`
   - `3 类 = 易燃液体`
2. 图 2：为什么不能靠近？
   - 汽油蒸气遇火更危险
   - 高度易燃，远离明火
   - 先远离，再报警，说清数字
3. 图 3：橙色矩形牌怎么读。
4. 图 4：上方数字速查。
5. 图 5：菱形牌看危险类别。
6. 图 6：特殊标志看额外风险。
7. 图 7：报警话术卡。
8. 图 8：尾图选择题。

常见危险性识别号简化含义：

- `20`：导致窒息的气体
- `23`：易燃气体
- `30`：易燃液体
- `33`：高度易燃液体
- `50`：氧化性物质
- `60`：毒性物质
- `80`：腐蚀性物质
- `X80`：遇水会发生危险反应的腐蚀性物质

使用提醒：

- 重复数字表示强调该类危险性。
- 末尾加 `0` 通常表示单一危险性由一个数字表示。
- `X` 开头表示遇水会发生危险反应。
- 具体解释以现行法规、标准或官方资料为准。

## 选题池

高优先级：

- 消火栓和水泵接合器，很多人真分不清
- 化工厂这 5 种消防设备，认错真的很危险
- 这 4 种报警器，响了不代表都一样
- 喷淋头、烟感、温感，别再混着叫了
- 危化品车后面的数字，不是车牌
- 油锅起火为什么不能浇水？
- 电器起火为什么不能先泼水？
- 有限空间救人，为什么不能第一个冲进去？
- 地下车库这些消防设备，你认得几个？
- 商场起火为什么不能坐电梯？

中优先级：

- 防火门为什么不能常开？
- 仓库冒烟后，第一反应别开门
- 消防车这 6 个接口，接错关键时刻没水
- 干粉消防车到底灭什么火？
- 泡沫消防车为什么不是只装泡沫？
- 加油站这几个红线动作，别碰
- 化工厂看到白雾，是水蒸气还是泄漏？
- 小区消防通道为什么不能占？
- 初起火灾扑救，什么时候该放弃灭火？
- 动火作业没审批，最危险的不是罚款

账号边界：

- 核心层 60%：消防设备识别、应急装备拆解、危化设施识别、错误操作后果。
- 扩展层 30%：商场、仓库、小区、地下车库、加油站、餐饮后厨、工业现场危险识别、事故前兆识别。
- 外围层 10%：节假日安全、法规政策、应急预案、管理流程。

宽泛可以，但每个选题都要落到三件事之一：认错、用错、判断错。
