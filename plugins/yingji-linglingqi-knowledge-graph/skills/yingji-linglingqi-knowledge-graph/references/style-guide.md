# 应急零零漆知识图谱视觉风格

## 总体定位

默认生成“手机端安全科普知识图谱海报”，画面要像成熟短图文账号的连续系列，而不是工程汇报、培训课件或普通宣传单。

核心观感：

- 白底或浅蓝灰底，整体明亮、干净、信息清晰。
- 大标题强冲击，主体大、文字大、重点一眼能读懂。
- 安全科普插画风，兼具扁平信息图和轻微写实质感。
- 红、深蓝、橙为主，绿色、紫色只用于辅助分类。
- 每张图都要有明确传播任务：点击、留人、收藏、分享或评论互动。

## 画幅与版面

- 默认 `3:4` 竖版，适合抖音、小红书和公众号图文。
- 顶部 20%-30% 留给标题区，标题必须醒目。
- 中部放主体设备、场景或核心图谱，是视觉重心。
- 底部优先放红色警示条、行动提醒或互动问题。
- 页面四周保留安全边距，不要让标题、图标或底部条贴边。
- 信息密度可以高，但必须分区明确，手机端能读。

## 标题区

标题风格：

- 使用超大号中文黑体感标题，粗重、直接、有冲击。
- 颜色优先使用安全红、深蓝和黑色，关键词可用红色强调。
- 标题可以带白色描边或轻微投影，增强移动端可读性。
- 副标题常用蓝色横幅、浅灰提示条或浅底提示条承接主标题。

标题写法：

- 优先写“认错、用错、判断错”的具体风险。
- 标识、编号、数字类主题，标题必须直接点出具体对象。
- 避免“XX 知识图谱”“XX 详细介绍”“XX 类型”这类说明书标题。

## 色彩系统

主色：

- 安全红：用于主标题关键词、警示条、危险项、重点结论。
- 深蓝：用于副标题横幅、编号标签、结构标题和理性说明。
- 橙色：用于危化、燃烧、注意项、第二重点信息。

辅助色：

- 绿色：用于正确做法、通过项、场景分类。
- 紫色：用于补充分组或互动选项。
- 浅蓝灰：用于背景、卡片分隔、远景城市或工厂轮廓。

禁止：

- 大面积黑底、赛博朋克、霓虹渐变、暗黑恐怖风。
- 单一红色铺满全图，导致层级混乱。
- 低饱和灰蓝企业 PPT 风。

## 插画与主体

主体画法：

- 设备、车辆、罐体、消火栓、标识牌要画得具体、可识别。
- 可使用干净的半写实插画质感：金属、管线、车辆、罐体允许有体积和高光。
- 消防员、安全员等人物使用卡通安全科普风，表情明确，动作服务提醒。
- 城市、厂区、道路、仓库等背景可以简化为浅色远景，不抢主体。

主体要求：

- 首图主体必须大，占画面视觉中心。
- 对比图要让不同对象并排出现，差异明显。
- 流程图要有清楚箭头和编号，不要只有装饰线。
- 标识、编号、危险牌必须尽量准确、清晰、可读。

## 信息组件

常用组件：

- 圆形编号：`1 / 2 / 3 / 4`，配红、蓝、橙、绿区分层级。
- 简洁信息分区：白底或浅底分区、浅灰分隔线、彩色顶部标签；不要把整张图做成大圆角容器或背景叠层。
- 蓝色横幅：用于副标题、依据标准、关键提示。
- 红色底部警示条：左侧警示三角或盾牌图标，右侧短句行动提醒。
- 对照表、识别表、流程卡、错误红黑榜、选择题卡片。
- 箭头、连线、放大框、局部标注，用来解释设备或标识。

图标风格：

- 使用安全相关图标：警灯、盾牌、火焰、感叹号、电话、放大镜、消防车、水滴、定位点。
- 图标要粗线条、扁平、饱和，不要细弱线框图标。

## 文字规则

- 所有画面文字默认简体中文。
- 主标题 8-18 字，短而有冲击。
- 节点名 4-8 字，说明短句 8-14 字。
- 卡片文字只放关键判断，不放长段法规原文。
- 强调词可以加红色，但每张图不要到处都红。
- 不能出现乱码、错别字、伪中文、无意义英文。

## 不同页面类型

### 首图

- 目标：让用户 1 秒内知道主题，并愿意点开。
- 结构：超大标题 + 强主体 + 3-5 个关键词或关键标识。
- 必须有明确冲突，例如“别看错”“认错很危险”“第一步别做错”。

### 图 2

- 目标：留住用户。
- 结构：只讲一个具体后果、一个强对比或一个反常识判断。
- 不要开始讲定义、分类、组成。

### 收藏页

- 目标：让用户截图保存。
- 结构：表格、清单、对照卡、流程卡或标注图。
- 可以信息较多，但必须用卡片、编号、图标分区。

### 尾图

- 目标：评论互动。
- 结构：大问题 + 2-4 个选项 + 留白 + 评论区引导。
- 问题必须普通用户能回答，避免高门槛专业考试感。

## 负面约束

出图时明确避免：

- PPT 汇报风、工程图纸风、政策宣传栏风。
- 纯照片感、真实事故血腥画面、恐吓式视觉。
- 文字过满、节点拥挤、卡片太小、标题太弱。
- 英文替代中文、无关装饰、随机 logo、水印。
- 把所有图都做成同一种网格结构。
