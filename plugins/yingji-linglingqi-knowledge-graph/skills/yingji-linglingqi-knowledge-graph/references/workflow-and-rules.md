# 工作流与硬规则

## 主题目录命名约定

项目根目录下的一级业务文件夹（即每一期主题的归档目录）必须遵守以下规则，方便按时间顺序回看、批量做复盘、防止出现"新建文件夹"这种无意义命名。

### 规则

- **格式**：`YYYY-MM-DD-主题名`
- **日期**：取该主题的立项日期，优先用目录原始创建时间（PowerShell `Get-ChildItem | Select CreationTime`）；如果目录创建时间不准确（例如从别处复制过来），用实际立项日。
- **主题名**：一句具体主题词，名词为主，不加"专题""系列""资料""汇总"等冗词。
- **子目录**：`images / Images / audio / assets / review / reference-from-ppt / gpt-image2-redo-*` 等保持原名，不在前面加时间戳。

### 批量归档脚本（PowerShell）

```powershell
$root = "E:\YuHonglei\应急零零漆"
Get-ChildItem -Path $root -Directory -Force |
    Where-Object { $_.Name -notin @('.git', '.skills') } |
    ForEach-Object {
        $ts = $_.CreationTime.ToString('yyyy-MM-dd')
        $newName = "${ts}-$($_.Name)"
        if ($_.Name -ne $newName) {
            Rename-Item -Path $_.FullName -NewName $newName
        }
    }
```

### 例外

- `.git`、`.skills` 等系统/配置目录不加时间戳。
- 已存在但无时间戳的历史目录，建议一次性批量补加（参考上面脚本），不强制要求随时改。
- 临时测试目录如果当天会删，可以保持原名；超过 24 小时还留着的，按规则补时间戳。

### 反例

- `新建文件夹`、`新专题`、`资料汇总`
- `2026.04.21-室外消火栓`（用点而不是横线）
- `室外消火栓_20260421`（日期放后面、字母序会乱）
- `20260421-室外消火栓`（日期不加分隔，不便读）

## 主题类型

先把主题归类，再决定指标与结构：

- 单设备类
- 系统类
- 对比类
- 流程类
- 巡检 / 误区类
- 法规政策类
- 场景应用类
- 装备科普类
- 标识 / 编码类
- 其他

指标判断：

- 设备识别：点击率 + 收藏率
- 设备拆解：点击率 + 收藏率 + 点赞率
- 对比：点击率 + 评论率
- 流程：图 2 留人 + 收藏率
- 巡检误区：分享率 + 收藏率
- 法规：点击率 + 收藏率 + 点赞率
- 装备：点击率 + 分享率
- 泛安全提醒：点击率 + 分享率
- 标识 / 编码：点击率 + 图 2 留人 + 收藏率

## 具体答案前置

凡是主题涉及数字、编号、标识、颜色、代码、等级、类别、符号，必须先进入“具体答案前置”。

硬规则：

1. 前两张图内必须给出至少一个具体示例的准确含义。
2. 图 1 标题优先包含具体示例本身，例如 `33/1203 是什么？`
3. 不能连续多张只说“不是装饰”“很重要”“看错会危险”。
4. 图 2 必须围绕具体含义讲具体风险或避险动作。
5. 图 3 优先做“位置 / 数字 / 含义 / 该怎么做”的收藏速查表。

示例：危化品车 `33/1203` 必须直接写：

- `33 = 高度易燃液体`
- `1203 = 汽油`
- `3 类 = 易燃液体`

## 爆款漏斗

- 图 1：封面点击，只回答“为什么点开”。
- 图 2：强留人，讲错误后果、反常识、真实风险或强对比。
- 中间图：硬核收藏，做识别表、对照表、流程卡、巡检清单、口诀卡、红黑榜。
- 尾图：低门槛互动，做选择题、找错题、猜名称、投票题。

禁止：

- 图 1 写成“XX 是什么 / XX 类型 / XX 作用 / XX 知识图谱 / XX 详细介绍”。
- 图 2 讲枯燥定义、分类、组成。
- 尾图写满或用高门槛专业问答。

## 前两图留人闸门

当前账号优先解决前两图掉人问题。除非用户明确要求其他指标，所有方案先过这个闸门：

### 图 1：1 秒停顿

首图必须让目标用户在 1 秒内产生“我可能认错 / 用错 / 判断错”的停顿。合格首图必须至少包含下面 2 类信息：

- 具体对象：设备、标识、罐体、车辆、场景、动作或数字。
- 具体冲突：看着相似但后果不同、常见叫法其实错、第一步容易做反、一个数字代表关键风险。
- 具体损失：会误判风险、报警说不清、巡检漏项、处置顺序错、企业被处罚或现场更危险。
- 具体答案钩子：直接露出一半答案，例如 `33=高度易燃`，但保留“为什么要远离 / 怎么报警 / 怎么识别”的继续翻页理由。

不合格首图：

- 只说“很重要、别忽视、不是装饰、你知道吗”。
- 只写主题名、知识图谱、类型介绍、详细讲解。
- 标题抽象，没有具体设备、数字、场景或错误动作。

### 图 2：继续翻页理由

图 2 必须承接图 1，并给用户一个继续看中间收藏页的理由。优先选择 1 个承接方式，不要混写完整分类：

- 后果揭示：认错之后会发生什么具体风险。
- 强对比：两个相似对象放一起，指出最关键差异。
- 反常识：用户以为该做 A，实际应先做 B。
- 第一步避错：现场第一动作、报警第一句话、巡检第一眼。
- 具体解码：把首图出现的数字、颜色、标识、部件解释清楚。

图 2 禁止：

- 从定义、分类、组成、正常功能开始。
- 重复图 1 的“危险、重要、别看错”。
- 同时讲 4 个以上知识点，导致用户还没被留住就先被劝退。

### 前两图固定交付字段

每次输出分图方案或提示词前，必须先写：

- 首图停顿点：用户为什么会停 1 秒。
- 图 2 承接点：图 2 如何兑现首图悬念。
- 继续翻页理由：用户为什么要看第 3 张收藏页。
- 不采用的弱写法：列出 1 个被放弃的说明书式标题或定义式图 2。

## 数据复盘改稿优先级

看到账号数据或单条作品数据时，先判断掉人环节，不要直接重做完整方案。

- 2 秒跳出率高于 40%：优先重写首图标题、首图主体和首图冲突点。
- 5 秒完播率低于 12%：优先重写图 2，不先动中间收藏页。
- 收藏率高但评论低：保留中间收藏页，重写尾图互动。
- 点击率高但完播低：首图方向可保留，重点改图 2 的承接。
- 点击率低但收藏率高：中间内容可能有价值，先重做首图包装。

复盘输出必须包含：

- 保留什么：哪类选题、哪种结构或哪张收藏页值得保留。
- 重写什么：图 1、图 2、尾图分别怎么改。
- 不做什么：本轮不扩大到整套风格、账号定位或发布频率，除非用户要求。

## 长期运营判断

账号复盘或月度排期时，必须先判断内容资产结构，再给选题。

### 内容资产判断

- 如果头部作品来自危化、化工、储罐、消防装备或消防设施，继续把这些作为核心爆款线。
- 如果法规、证书、作业票、SDS、台账类作品播放中等但收藏稳定，归入职业价值线，不要因为播放不如爆款就放弃。
- 如果视频短片或泛热点播放波动大，归入热点解释线，只保留少量测试。
- 如果平均浏览图片长期低于 2.5，优先优化前两图，不先增加张数。
- 如果评论量长期低，尾图必须从开放问答改成选择题、找错题或判断题。

### 月度排期默认比例

- 核心爆款线 60%：危化 / 化工 / 储罐 / 消防装备 / 消防设施 / 现场避错。
- 职业价值线 25%：安全员、班组长、企业培训、证书边界、作业票、SDS、台账和检查表。
- 热点解释线 15%：事故案例、节假日、天气、校园、社区和家庭安全，但必须改造成具体风险场景。

### 复盘沉淀要求

每次账号复盘后，必须输出 3 个清单：

- 继续复制：哪些选题主线、首图钩子和收藏页结构继续用。
- 降频测试：哪些主题只能少量测试，不能变成主线。
- 进入禁用：哪些标题、图 2 写法或尾图问题暂时不用。

### 钩子去重

连续排期时检查最近 5 条内容：

- 如果 3 条以上都写“第一步别错”，下一条必须改用认错、数字解码、查漏或判断题钩子。
- 如果 3 条以上都写“认错很危险”，下一条必须改用具体后果、具体数字或现场判断。
- 如果连续法规 / 标准主题播放下滑，下一条必须回到设备识别、危化场景或消防设施识别。

## 关键信息核验

选题规划时必须回答：

- 用户最想知道的具体答案是什么？
- 是否涉及数字、编号、标识、颜色、代码、等级或类别？
- 如果涉及，前两张图要直接讲哪个具体示例？
- 是否有不确定信息需要先查证？

如果关键信息没有核验清楚，不能进入出图方案。

## 调研优先级

优先使用：

1. 官方法规、国家标准、行业标准、政府公开资料。
2. 消防、应急、交通、住建、市场监管等主管部门资料。
3. 事故调查报告、权威机构安全提示。
4. 设备厂家公开说明、产品样本、技术手册。
5. 高质量媒体报道和科普内容，只作为补充，不替代官方依据。

调研输出必须区分“已确认事实”和“推断”。不确定内容不要写进图上的硬结论。

## 生成前自检

输出完整出图方案前检查：

- 前两张图是否给出具体答案，而不是只讲重要性？
- 图 1 是否能让用户 1 秒内知道这期讲什么？
- 图 1 是否有具体对象、具体冲突或具体错误动作？
- 图 2 是否承接图 1，并讲具体风险、具体后果、强对比、反常识或第一步避错？
- 图 2 是否给出继续看第 3 张收藏页的理由？
- 是否至少有 1 张图适合截图保存？
- 尾图是否是普通用户也能回答的选择题、找错题或猜含义题？

任何一项不通过，先调整分图规划，再输出提示词。

## 最高优先禁止项

- 禁止只讲知识，不考虑传播指标。
- 禁止数字 / 编号 / 标识 / 颜色 / 代码类选题只讲重要性不讲具体含义。
- 禁止连续 2 张以上铺垫“看错很危险”“不是装饰”“要说清”。
- 禁止第 2 张图讲枯燥定义。
- 禁止固定套用统一张数模板。
- 禁止尾图写满。
- 禁止输出模糊、不可执行的生图提示词。
- 禁止所有图片都做成同一种结构。
- 禁止写成工程报告、说明书、政策公文。
- 禁止看到数据后直接重做完整方案，必须先复盘诊断。
