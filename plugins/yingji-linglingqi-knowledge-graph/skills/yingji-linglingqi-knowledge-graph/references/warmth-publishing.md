# 温情共鸣与发布文案

核心原则：看懂危险，是为了让人平安回家。

## 使用边界

推荐比例：

- 80% 硬知识
- 20% 情绪连接

适合加入温情线的位置：

- 封面副标题
- 图 2 风险后果
- 底部警示条
- 发布文案前三行
- 发布文案结尾
- 尾图互动问题

不建议：

- 每张图都讲家人
- 用过度煽情标题
- 用恐吓式表达
- 用“如果不看就会出事”这类焦虑话术
- 把专业内容改成鸡汤

## 平安回家模型

适用主题：危化品车数字、消防通道、防火门、有限空间作业、动火作业、油锅起火、电器起火、商场起火、小区消防设施、地下车库安全、加油站安全、危化企业现场识别、仓库火灾隐患、消防报警与应急处置。

核心逻辑：用户不是为了“上课”而看安全内容，而是为了知道遇到危险时怎么保护自己、提醒家人、帮助同事少犯错。

标准结构：

1. 图 1：危险识别 + 平安回家关联。
2. 图 2：错误动作带来的真实代价。
3. 图 3-6：硬核知识图，保持识别表、流程卡、错误对照表、清单。
4. 尾图：低门槛情绪互动。

注意：

- 温情表达只做点睛，不能替代具体知识。
- 数字、标识、编号类选题仍然必须先讲具体含义。
- 流程类选题仍然必须先讲第一步做错的具体后果。

## 首图温情写法

推荐结构：

- 主标题：认错 / 用错 / 判断错的具体风险。
- 副标题：把风险和人连接起来。
- 底部警示：简短、克制、有行动指向。

示例：

- 危化品车数字：`33/1203 是什么？`；副标题：看懂它，是为了离危险远一点；底部：先远离，再报警，平安最重要。
- 消防通道：消防通道被堵，真不是小事；副标题：给消防车留路，也是给家人留安全；底部：别占通道，关键时刻真会耽误救命。
- 防火门：防火门常开，危险会变快；副标题：关上的不是麻烦，是烟火蔓延的速度；底部：防火门常闭，是给楼里人多一点时间。

## 图 2 风险后果写法

推荐表达：

- 不是看热闹，是把自己暴露在风险里。
- 多靠近一步，风险就多一分。
- 你以为只是拍个视频，现场可能正在争分夺秒。
- 错误动作不是小失误，可能会放大事故。
- 先远离，不是胆小，是对自己和家人负责。
- 不乱冲，不围观，是给救援留空间。

避免表达：

- 别让妈妈哭。
- 一个动作毁掉一个家庭。
- 不看就可能回不了家。
- 你可能再也见不到家人。
- 过度恐吓和廉价煽情。

## 底部警示条文案库

通用：

- 看懂危险，是为了平安回家
- 少靠近一步，多一分安全
- 安全回家，比拍清楚更重要
- 先远离，再报警，别冒险
- 别围观，别冒险，别让家人担心
- 你远离的不是麻烦，是危险
- 不是怕事，是对安全负责
- 多看懂一个标识，少一次冒险

场景：

- 危化车：先看标识，再判断风险；说清数字，救援更快；不靠近拍照，先离开危险区。
- 消防通道：给消防车让路，就是给救援争时间；通道留出来，关键时刻才进得去。
- 防火门：防火门常闭，烟火蔓延慢一步；关好这扇门，是给大家多一点时间。
- 有限空间：别盲目救人，先保护自己；好心不能代替防护；先报警、先通风、先防护。
- 动火作业：动火前多确认一次，事故就少一分；不是手续麻烦，是风险真的高。

## 发布文案落盘规则

- 生成发布文案后，必须写入当前项目目录的主题文件夹。
- 推荐文件名：`发布文案.md`。
- 文件内容至少包含：爆款标题、正文描述、置顶神评、标签、SEO 关键词、尾图互动引导。
- 如果同一主题有多个平台版本，可使用 `发布文案-抖音.md`、`发布文案-小红书.md`、`发布文案-公众号.md`。
- 不要只在对话里输出文案而不保存文件。

### 普通大众向

很多安全知识，看起来离我们很远。  
但真遇到危险时，差别往往就在一个动作：  
是靠近看热闹，还是先远离报警。

这期把最容易看错的地方整理成图。  
不是为了让你背知识，而是希望你在路上、小区、单位看到类似情况时，知道怎么保护自己。

建议收藏，也可以转给经常开车、通勤、在厂区或仓库工作的家人朋友。  
有些提醒，用不上最好；真遇到时，能想起来就很重要。

### 家人提醒向

这类安全标识，很多人平时见过，但真不一定看懂。  
看懂它，不是为了显得专业，而是为了遇到危险时少靠近一步、少一次误判。

图里整理了识别方法、风险含义和正确做法。  
适合收藏，也适合转给家里经常开车、路上通勤、在工厂或园区上班的人。

安全不是小题大做。  
很多时候，知道该远离，比凑近看清楚更重要。

### 企业 / 班组向

现场安全不只靠制度，也靠每个人能不能看懂风险。  
很多事故不是没人反应，而是第一步判断错了。

这套图适合班组、安全员、值班人员和一线岗位收藏。  
遇到类似情况时，先识别、先远离、再报告，别把自己暴露在风险里。

真正的安全管理，不是出了事才紧张，  
而是平时就让每个人知道哪些动作不能做。

## 尾图互动问题库

低门槛情绪互动：

- 你会把这张图转给谁？
- 你最想提醒家人哪一点？
- 如果家人路上遇到这种情况，你会提醒他怎么做？
- 你身边有人做过这个危险动作吗？
- 你觉得哪一步最容易被忽略？

选择题互动：

- 如果你在路上看到疑似泄漏，第一步选哪个？
- A 靠近看清数字
- B 拍视频发群里
- C 远离现场并报警
- D 用水冲一冲

找错题互动：

- 图里哪个动作最危险？
- 这 4 个做法里，哪个最不该做？
- 你觉得哪种行为最容易害人？

选题征集：

- 下期想看哪个：消防通道 / 防火门 / 油锅起火 / 有限空间？
- 你还想看哪些“平时见过但不知道怎么用”的安全设施？

## 温情牌检查表

使用前检查：

1. 有没有保留具体知识点？
2. 有没有避免过度煽情？
3. 有没有给用户一个转发给家人 / 同事的理由？
4. 有没有明确行动建议？
5. 有没有让普通人也能参与评论？

修正方式：

- 如果太冷：在副标题、底部警示或文案前三行加一句“平安回家”相关表达。
- 如果太煽情：删掉夸张后果，改成“少靠近一步、多一分安全”。
- 如果太空泛：补回具体数字、标识、步骤、判断表或错误对照。
