# 公众号图片与 AI 出图提示词

## 通用提示词结构

提示词要写成视觉设计任务书，包含：

```text
用途 / 平台
主题 / 目标
画面主体
场景环境
构图方式
视觉风格
必须出现的文字
负面约束
输出比例 / 尺寸 / 质量要求
```

顺序：

1. 说明图片用来做什么。
2. 说明画面中有什么。
3. 说明文字写什么。
4. 说明风格和构图。
5. 说明不要什么。

## 微信公众号尺寸

头条封面：

- 推荐尺寸：900×383 px
- 比例：约 2.35:1
- 用途：公众号文章头条封面、订阅号消息流大图

次条封面：

- 推荐尺寸：200×200 px 或 500×500 px
- 比例：1:1

正文配图：

- 常用宽度：900 px 或 1080 px
- 常见比例：16:9、4:3、3:4、长图均可
- 正文配图不是头条封面，不要套用 2.35:1

## 中文文字入图

要求：

- 当前 AI 出图工具可以直接生成中文，封面图和正文知识图应优先直接生成含中文标题、栏目词、短标签或流程词的成品图，不要默认先生成无文字图再后期叠加。
- 文字使用简体中文。
- 所有中文清晰可读，不能有乱码、错别字、伪中文。
- 只允许出现指定文字，不自动添加额外标题、英文或编号。
- 主标题最大，副标题次之。
- 文字和背景有足够对比度。
- 不让文字压在复杂背景上。
- 每张图只讲一个核心问题。
- 生成后必须视觉检查中文是否准确；如果有错字、乱码、漏字或语义不准，优先重生成或改为更短文字。
- 只有多次生成失败、需要强版式控制，或用户明确要求时，才使用本地后期叠字。

## 公众号头条封面模板

```text
生成一张 900×383 px、2.35:1 横向比例的微信公众号头条封面图。

【主题】
图片主题是：【填写文章主题】。

【目标】
在订阅号消息流的缩略图状态下，让读者一眼看懂主题，并产生点击欲，但不要制造恐慌。

【画面主体】
核心主体是：【设备 / 场景 / 标识 / 人物 / 对比对象】。
主体位于：【左侧 / 右侧 / 中心】，画面留出清晰标题区域。

【构图】
采用：【左右对比 / 中心主视觉 + 标题区 / 场景悬念 / 红圈箭头标注 / 专业图谱感】。
画面主次分明，信息不要堆满，不要提前暴露正文全部答案。

【文字要求】
必须出现以下中文文字，逐字准确：
主标题：“……”
副标题：“……”

【风格】
专业、清晰、有现场感，适合应急安全科普公众号。不要像传统 PPT，不要低俗标题党。

【限制】
不要水印，不要 Logo，不要英文乱码，不要伪中文，不要血腥事故画面，不要过度拥挤。
```

## 正文知识图模板

```text
生成一张微信公众号正文知识图，宽度 900 px，适合手机阅读。

【主题】
这张图解释：【一个核心知识点】。

【信息结构】
请分成【流程 / 对比 / 分类 / 时间线 / 风险分层 / 操作边界】。
每个信息块只放一组内容。

【文字要求】
必须出现以下中文文字，逐字准确：
标题：“……”
要点：
1. “……”
2. “……”
3. “……”

【视觉要求】
信息层级清楚，图标克制，配色专业，适合公众号正文阅读。

【限制】
不要把整篇文章塞进一张图，不要复杂背景，不要乱码，不要额外添加文字。
```

## 应急安全类负面约束

生成或策划图片时避免：

- 血腥、伤亡、尸体、恐怖画面。
- 夸张爆炸冲击波、灾难大片感。
- 引导围观、拍摄、靠近危险源的画面。
- 错误消防装备、错误警示标识、错误 PPE 穿戴。
- 把标准条文截图当封面。
- 一张图塞满文字。

## 出图自检

发布前检查：

- 比例是否符合用途。
- 中文文字是否逐字准确。
- 主题是否一眼可见。
- 是否有恐慌、猎奇或事实错误。
- 是否适合移动端缩略图。
- 是否没有多余 Logo、水印、乱码。
