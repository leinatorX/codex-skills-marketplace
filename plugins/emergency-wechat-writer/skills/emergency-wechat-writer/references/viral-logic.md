# 公众号爆款逻辑

## 底层公式

通用公式：

```text
常见事物 + 用户误解 + 专业解释 + 大白话表达 + 可视化呈现 + 可转发价值
= 公众号爆款内容
```

应急安全类公式：

```text
一个常见安全场景 + 一个容易犯的错误 + 一个专业但不难懂的解释 + 一个关键行动建议 + 一个转发给身边人的理由
= 安全科普爆款
```

## 高潜力选题

- 常见但分不清：消防装备、化工设备、安全设施、危险品标识。
- 不是随便来的：颜色、标识、警示牌、消防配置、标准要求。
- 看似简单，其实很危险：有限空间、动火作业、报警器、泄漏、初期处置。
- 事故之后看门道：热点新闻后的专业解释，不猎奇、不渲染灾难。
- 新标准大白话：法规、标准、政策、行业文件解读。
- 普通人不用背，但要知道：把专业知识转化为公众安全认知。

## 选题判断

一个选题命中 5 条以上，可以进入选题池：

1. 普通人是否见过。
2. 普通人是否容易误解。
3. 行业内是否有专业标准或规范依据。
4. 能不能用一张图讲清楚。
5. 标题能不能制造认知差。
6. 封面能不能形成视觉冲突。
7. 结尾有没有转发给别人看的理由。
8. 发布后是否还能被搜索到。

## 标题结构

推荐：

- 《很多人都分不清的……》
- 《……不是随便来的》
- 《……真正危险的不是……》
- 《看懂……，关键看这几点》
- 《……不用硬背，但一定要知道》
- 《……背后的安全逻辑》
- 《为什么……不能只看……？》

避免：

- 低俗、恐吓、耸动标题。
- “全网最全”“震惊”“出大事了”等夸张表达。
- 标题把答案讲完，导致用户失去点击理由。
- 标题专业词堆叠，普通读者看不懂。

## 正文节奏

推荐结构：

1. 开头场景：从读者见过、听过、误解过的点切入。
2. 误区拆解：先说容易错在哪。
3. 专业解释：引用标准、原理、流程或案例。
4. 大白话转换：把专业内容讲成普通人能懂的话。
5. 场景应用：普通人、企业、管理者分别该怎么做。
6. 结尾提醒：给出转发、收藏或评论理由。

每一节只解决一个问题，避免一节塞多个结论。

## 封面规则

公众号头条封面优先：

- 900×383 px
- 2.35:1 横向比例
- 大标题清晰，主视觉明确
- 缩略图状态下也能看清主题
- 留白合理，不把信息堆满
- 不提前暴露全文答案

适合构图：

- 左右对比
- 红圈、箭头、问号
- 设备特写
- 场景悬念
- 常见错误示意
- 专业图谱感构图

不适合：

- 传统 PPT 感
- 文字堆满
- 标准条文截图
- 多元素拼贴
- 恐怖事故现场

## 转发与收藏理由

结尾可以围绕这些理由设计：

- 转给家人：知道怎么避险。
- 转给同事：现场别踩坑。
- 转给企业负责人：知道哪些环节必须落实。
- 收藏备用：遇到类似情况能快速看懂。
- 评论互动：请读者说说自己见过的误区。
