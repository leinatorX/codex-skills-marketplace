# 示例输入：安信企业汇报

目标：生成一份 8 页以内的蓝白企业汇报风 HTML PPT，用于客户拜访。

受众：园区安全负责人、应急管理相关领导、保险公司风险减量团队。

核心材料：

- 公司定位：数智赋能的安全应急领域解决方案平台。
- 核心能力：虚拟仿真、硬件感知、AI 预警、RAG 数据治理、FLACS 推演合作。
- 典型场景：危化园区、石油化工、港口码头、危化品运输事故。
- 主推方向：安委会培训、大范围速扫、输转模块、安责险风控平台。
- 汇报目标：让客户理解安信不是单一产品供应商，而是能把预案、感知、推演、培训和保险风控连接成闭环的平台。

要求：

- 封面使用全屏背景图 + 中文大标题。
- 第二页是目录，按“背景、问题、方案、证明、行动”组织。
- 页面标题使用中文结论句，不要中英混排。
- 生成后运行校验、截图并打包 zip。
