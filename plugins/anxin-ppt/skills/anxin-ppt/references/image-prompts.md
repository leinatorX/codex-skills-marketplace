# 安信 PPT 配图提示词

本文件用于配合 `anxin-image-gen` 生成蓝白企业汇报风 PPT 配图。

## 总原则

- 提示词默认使用简体中文。
- 图片应服务 PPT 页面，不要生成完整 PPT 页面。
- 不要生成页眉、页脚、页码、标题栏、水印、署名。
- 不要把“无文字、无 Logo”写成所有图片的固定后缀。根据图片用途决定：
  - 封面和品牌页：允许出现真实品牌标识、产品标识或门店/车身/设备上的真实标识，但不要生成伪造 Logo。
  - 产品图和真实场景图：允许产品铭牌、车标、包装标识、设备界面等自然存在的文字。
  - 架构图、流程图、关系图：文字应由 HTML 页面承载；如果必须在图内标注，只使用少量简体中文短标签。
  - 背景图和氛围图：可以要求无文字、无水印。
- 不要使用不必要的英文文字。
- 风格为蓝白企业汇报，干净、可信、专业。
- 避免霓虹、赛博、玻璃拟态、夸张 3D、营销海报感。
- 构图必须完整展示主体，不要近距离切脸、切车头、切设备边缘；为页面标题和说明留出安全留白。

## 尺寸建议

| 用途 | 接口尺寸 | 说明 |
|---|---:|---|
| 封面主视觉 | 2048x1152 | 16:9 横图，适合右侧或全幅主视觉 |
| 架构图 / 方案图 | 2048x1152 | 16:9，适合大图展示 |
| 业务闭环图 | 1536x1024 | 3:2，适合图文混排 |
| 产品图 / 场景图 | 1536x1024 | 横图，适合卡片或左图右文 |
| 图标组 | 1024x1024 | 方图，后续可裁切 |

生成前先确定页面使用的图片槽位。`image-16x9` 对应 2048x1152，`image-3x2` 对应 1536x1024。不要把 16:9 图片放进 3:2 槽位，也不要把 3:2 图片放进 16:9 槽位。

## 封面主视觉

```text
生成一张 2048x1152 的企业汇报封面主视觉，用于安全应急数智化解决方案 PPT。
画面主体是现代化应急指挥中心、化工园区、数据平台大屏和现场处置人员的抽象组合。
整体蓝白配色，干净、专业、可信，适合政府、协会和大型企业客户汇报。
构图右侧主体更丰富，左侧保留充足留白，方便 HTML 页面叠加中文标题。
不要出现英文标题、水印、页码、边框、夸张火灾、人员伤亡、灾难化画面。若是安信品牌正式封面，需要使用真实品牌标识时应使用用户提供的素材，不要让模型伪造。
```

## 技术架构图

```text
生成一张 2048x1152 的蓝白企业风技术架构图素材。
主题是安全应急平台技术架构，包含感知设备、边缘计算、数据治理、仿真引擎、AI 预警、指挥应用等层级。
使用简洁模块、细线连接、浅蓝背景、深蓝重点模块，整体像正式企业汇报中的架构图。
图中文字尽量少，只使用简体中文短标签；不要出现英文乱码或多余文字。
不要生成 PPT 页眉、页脚、标题栏、水印和页码。
```

## 解决方案闭环图

```text
生成一张 2048x1152 的蓝白企业风解决方案闭环图素材。
主题是从风险识别、预案建模、监测预警、仿真推演、指挥调度、复盘评估到持续治理的闭环。
画面采用环形或横向流程结构，模块清晰、留白充足、层级分明。
颜色使用白色、浅蓝、深蓝和少量青蓝强调，不要使用霓虹、渐变和花哨装饰。
图中文字使用简体中文短标签，不要多余英文、水印、页码或 PPT 外壳。
```
