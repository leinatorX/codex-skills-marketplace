# 企业汇报叙事主线

生成 PPT 前先选一条主线。主线决定页面顺序，版式只服务主线。

## 1. 解决方案汇报

适合：客户拜访、政府采购、园区方案、企业安全能力建设。

```text
现状压力 -> 关键缺口 -> 方案闭环 -> 能力证明 -> 落地路径 -> 合作建议
```

推荐页面：

1. 封面：一句话方案主题
2. 目录：从问题到落地的汇报路径
3. 现状压力：为什么客户现在需要行动
4. 关键缺口：传统管理方式解决不了什么
5. 方案闭环：用一张图讲清整体解法
6. 能力证明：平台、产品、专家、案例或数据
7. 落地路径：试点、建设、运营、评估
8. 合作建议：需要客户或伙伴做出的下一步动作

## 2. 协会 / 专委会介绍

适合：危化专委会、行业协会、重点实验室、联盟平台介绍。

```text
为什么成立 -> 要解决什么行业缺口 -> 如何组织资源 -> 已经有什么基础 -> 下一步如何落地
```

推荐页面：

1. 封面：专委会名称或核心使命
2. 目录：成立背景、平台定位、资源组织、工作基础、行动建议
3. 成立背景：政策、行业、风险治理为什么需要这个平台
4. 平台定位：专委会不是名单集合，而是专家、标准、服务和数字化的枢纽
5. 资源组织：政府、保司、企业、专家、技术机构如何被连接
6. 工作基础：只放 3-5 个最能证明能力的数据或代表活动
7. 重点抓手：标准、培训、安责险、数字化平台等年度动作
8. 合作建议：不同对象能参与什么、获得什么

## 3. 公司介绍

适合：公司拜访、合作伙伴介绍、路演开场。

```text
我们是谁 -> 服务谁 -> 解决什么问题 -> 凭什么能做 -> 今年重点推什么
```

推荐页面：

1. 封面：公司一句话定位
2. 目录：定位、场景、方案、能力、产品、抓手
3. 公司定位：聚焦行业与核心客户
4. 场景问题：客户面临的安全、应急、监管或经营压力
5. 方案闭环：虚拟仿真、硬件、AI、数据和服务如何组合
6. 能力证明：客户、案例、合作、数据或资质
7. 产品矩阵：只放主推产品，不放完整货架
8. 年度抓手：接下来最适合推进的业务线

## 4. 安责险业务汇报

适合：保险公司、监管平台、协会平台、服务机构合作。

```text
市场变化 -> 风险减量缺口 -> 平台服务模型 -> 数据与标准能力 -> 商业闭环
```

推荐页面：

1. 封面：安责险风险减量主题
2. 目录：市场、缺口、模型、能力、落地
3. 市场变化：政策和保费规模带来的窗口
4. 风险减量缺口：保司、企业、服务机构各自痛点
5. 平台服务模型：投保、排查、整改、培训、评估闭环
6. 数据与标准：分类分级、隐患库、服务评价和效果评估
7. 试点路径：区域、行业、保司和服务商推进节奏
8. 合作收益：各方为什么愿意参与

## 判断页面是否有逻辑

逐页问这 4 个问题：

- 这一页是否回答了一个明确问题？
- 本页结论是否能用一句话说清？
- 它和上一页是因果、递进、证明还是行动关系？
- 如果删掉这一页，主线是否断裂？

如果答案不清楚，说明这一页只是素材堆放，需要重写或删除。
